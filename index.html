Project Overview

The final deliverable is a high-fidelity mobile prototype designed for a non-profit/community platform. It demonstrates the visual and functional direction for an app that supports youth engagement, creativity, and connection through dance battles, workshops, and social resources.

Core Features (3–5)

  • Registration / Sign-up – onboarding users into the app
  • Activity / Dance Battles – participate or spectate youth-driven challenges
  • Calendar – track upcoming events, workshops, and programs
  • Resource Center – guides, articles, and community materials
  • About & Contact – info on the project and contact form

Main Feature

The “Battle” section includes multiple pages that show how youth can create and join dance-based challenges with profiles and community feedback features. Flow is demonstrated in the prototype.

Final Project Objectives

  • Applied design principles: color, type, hierarchy, layout
  • User-centered and inclusive interaction design
  • Mobile-first responsive interface
  • Demonstrated UX concepts via a clickable prototype
  • Frame sizes based on iPhone 13 screen specs
